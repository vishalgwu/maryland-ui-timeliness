Maryland vs. the Nation: State Maps of UI Payment Timeliness

Hover a state for its numbers. Source: US DOL ETA 9050 (public), my calculation.

Timeliness = first payments within 21 days of the first compensable week / all first payments (intrastate + interstate). Puerto Rico and the Virgin Islands are in the data but not drawn. The base map loads from Plotly's CDN, so open this page online.
